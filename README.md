# bref Dictionary

A searchable, installable, offline-capable dictionary for **bref**, the alphabetic
shorthand system created by **Donald M. Volk** — plus a converter that compresses
plain English into bref.

**→ [Open it](https://mtaran.github.io/bref-dictionary/)**

Built from the [Toki Pona Dictionary](https://github.com/mtaran/toki-pona-dictionary)
as a template: same single-page app shell, scored search, service worker and web
manifest.

## What's in it

- **11,661 words** — the complete bref word dictionary
- **One search box, always both directions.** Type English to get the brief, or
  type a brief to expand it. `because → bcs`, `bcs → because`. Exact matches rank
  first, then prefixes, then substrings, then matches on the far side of the entry
- **Converter** — a modal behind the `converter` button. Type or paste English and
  get bref out, with a copy button and a compression readout. Your text is kept in
  `localStorage`, so it's still there next time
- **Installable PWA** — add to home screen; everything is cached, so it works with
  no network
- Light and dark themes; press <kbd>/</kbd> to jump to the search box, <kbd>Esc</kbd>
  to close the converter

For the rules, the alphabet and reading practice, see the companion page:
**[bref — one-page reference](https://mtaran.github.io/bref-shorthand/)**.

### How the converter works

Word by word, against the dictionary. A word is matched **case-sensitively first**,
so `March` (mar) stays distinct from `march` (mrc); failing that it falls back to a
lowercase lookup, so a sentence-initial `The` still resolves to the everyday word.
The only genuinely ambiguous entries are `March`/`march` and `May`/`may` — a
sentence-initial `May` is read as the month.

Punctuation that would need a shift key is replaced with its lower-case stand-in
(`?` → `/`, `!` → `//`, `%` → `,,`, `:` → `;;`, `(` → `[[`, `)` → `]]`, `$` → `==`),
apostrophes are dropped from contractions and possessives, and numerals are left
alone. Words the dictionary doesn't carry pass through unchanged and are underlined
in the output.

Checked against the manual's own worked examples: **14 of 14** sentences the author
transcribes by hand come out character-for-character identical.

Because the converter works a word at a time, it won't produce the author's
**phrase** briefs — the manual writes *to be* as `tb`, whereas this gives `t b`.
The phrase list is not carried here (see below).

## Data

`dictionary.json` is generated by `build_dictionary.py` from the author's word lists
in `source/`.

bref is a **bijection** — every brief expands to exactly one English word — so each
pair is stored once and both search directions are derived at load time. That is the
one structural departure from the Toki Pona template, whose two directions carry
genuinely different content. It keeps the offline payload at ~226 KB for 23,322
searchable entries. The build verifies on every run that no brief expands to two
different words (currently 11,661 briefs, 0 collisions).

The author also publishes a **3,037-entry phrase list**. It is deliberately not
carried here, to keep the app to a single searchable word list; get it from the
Drive folder linked below.

Three defects in the source lists are corrected:

- `exam = xmexam = xm` — a typo; the intended brief is `xm`
- `government` — the FORWARD list gives `gvr`, the REVERSED list gives `gvt`; `gvt`
  is used, since `governments = gvts`
- **`a` is missing entirely.** It is its own brief, so it was presumably skipped as
  a no-op, but the manual gives it in both the alphabet table (`a = a`) and the
  most-frequent-words list, and the brief `a` is otherwise unused. Restoring it
  brings the count to 11,661 — matching the author's own filename,
  `11661 WORDS FORWARD.txt`, which lists 11,660. Without it the converter flags
  every *a* as an unknown word.

Where the manual's prose and the dictionary files disagree, the dictionary files
win, since that is what the author's EXPAND text-expander actually runs on.

Note for anyone else parsing these files: the word lists are English-first, but the
*phrase* lists use the opposite column order.

## Rebuilding

```sh
python3 build_dictionary.py   # regenerates dictionary.json, favicon.svg and the icons
```

No dependencies — the icons are rasterised by a small PNG encoder in the script.
